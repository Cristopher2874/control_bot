# T3.2: Clasificador local y contexto contaminado

- **Fase:** 3
- **Estado:** Pendiente
- **Depende de:** T3.1, T2.1

## Objetivo

Lo que las reglas no deciden lo clasifica un modelo local. Cualquier dato privado que entre a mitad del run lo fija a local hasta el final. Hay tests que demuestran que nada privado llega a la nube. Cierra la Fase 3.

## Contexto mínimo

- **Clasificador:** si las reglas dan `unknown`, `ask_structured` (T2.1) con el perfil `light` (gemma4:e2b, local) y schema `{"sensitivity": "private" | "public"}`. Si falla, tarda demasiado o devuelve algo inválido, el resultado es `private`. Nunca se usa un perfil cloud para clasificar.
- **Contaminación:** el `RunContext` pasa a `private`, y ya no vuelve a cambiar, cuando entra al run cualquiera de estas cosas:
  - la salida de una tool de una capability con `data_sensitivity: private`;
  - un mensaje de memoria marcado `private` (T4.x, deja el punto de enganche listo);
  - el contenido de un archivo leído.
- **El punto de enganche** es el executor (T2.2): al devolver un `ToolResult`, marca el contexto según el manifest de la capability. Así ninguna tool nueva puede olvidarse.
- **Caso típico a evitar:** la pregunta es pública, se decide cloud, una tool devuelve datos del PC y la siguiente llamada se iría a la nube. Con la contaminación, la siguiente llamada se re-enruta a local y queda `route_reason: "tainted"`.

## Alcance

**Incluye:** clasificador, contaminación en el executor y en el `RunContext`, re-enrutado por paso, tests de no-fuga.

**Fuera de alcance:** memoria persistente (T4.1). Evals del clasificador (TE.2).

1. Clasificador con timeout y fallback a `private`.
2. `RunContext.taint(source)` y su llamada desde el executor.

## Output esperado

`harness chat "explícame en detalle la transformada de Laplace"` va a cloud (`heavy_public`), y `harness run "¿qué ventanas tengo abiertas? resúmelo en detalle"` se queda en local aunque el texto parezca pesado.

## Tests mínimos

En `test_privacy_no_leak.py`, con un `FakeProvider` que registra el perfil de cada llamada:

- `test_contaminacion_a_mitad_del_run`: primera llamada pública a cloud; una tool `private` devuelve datos; **todas** las llamadas siguientes van a perfiles `local`.
- `test_clasificador_falla_es_privado`: el clasificador devuelve basura o se agota el tiempo → local.
- `test_ningun_privado_llega_a_cloud`: recorre una lista de ~10 escenarios (reglas, clasificador, tool, override) y comprueba que el `FakeProvider` cloud nunca recibió un mensaje de un contexto `private`.
- `test_clasificador_real` (`@pytest.mark.ollama`): 4 o 5 frases evidentes con `gemma4:e2b`.
